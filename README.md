## 📖 简介

本仓库收录了一组 **AI 的拟人化形象**（把 AI 助手/模型画成人物角色）。

**为什么要做拟人化？**
网络上有大量泛娱乐用户喜欢这样做：把抽象的 AI 变成有性格、有外观、有"人设"的角色，更亲切、更好玩，也更容易被讨论、二创和传播。本项目就是顺着这个潮流整理的一份图集，希望能给喜欢这类内容的朋友提供素材和灵感。

本图集由 小叶子XIYZ 与 vibebar共同创作，两位作者均同意以 CC0 1.0 协议发布。
图中出现的名称仅用于指明所拟人化的对象，不代表官方形象，也与官方无关；相关名称与 Logo 的权利归各 AI 公司所有。
本库仅用于存放和分享这些图片。

## 📁 目录结构

| 文件夹 | 内容 | 格式 |
| --- | --- | --- |
| `png1/` | 角色**主视图**（主视角） | PNG |
| `jpg3/` | 角色**三视图**（侧面 / 正面 / 侧面） | JPG |
| `webp3/` | 角色**三视图**（同上，体积更小的版本） | WebP |

每个角色在三个文件夹中使用相同的文件名（如 `cl.png` / `cl.jpg` / `cl.webp`）。
